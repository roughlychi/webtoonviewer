# 이미지 비교 뷰어

내 컴퓨터의 이미지를 열 단위로 불러와, 원본과 수정본을 나란히 놓고 위아래로 스크롤하며 비교하는 웹 뷰어입니다.
이미지는 서버로 올라가지 않고 브라우저 안에서만 처리됩니다.

## 사용법

| 조작                            | 동작                                                               |
| ------------------------------- | ------------------------------------------------------------------ |
| **파일 선택**                   | 이미지를 여러 장 고릅니다. 파일명 순서(숫자는 숫자 순)로 쌓입니다. |
| 휠                              | 모든 열이 같이 스크롤됩니다.                                       |
| Shift + 휠                      | 마우스를 올린 열만 스크롤됩니다. 어긋난 위치를 맞출 때 씁니다.     |
| Ctrl + 휠 (트랙패드는 핀치)     | 모든 열이 같이 확대·축소됩니다.                                    |
| **≡** 끌기                      | 열의 위치를 바꿉니다. 파란 선이 들어갈 자리를 보여줍니다.          |
| **+ 열 추가** / **열 닫기**     | 열은 최대 3개입니다.                                               |
| **▲ 맨 위로** / **▼ 맨 아래로** | 모든 열을 끝으로 보냅니다.                                         |
| 확대 비율 버튼                  | 누르면 100%로 돌아갑니다.                                          |
| 이미지 위에 마우스              | 파일명이 나타납니다.                                               |
| 해·달 아이콘                    | 밝은 화면과 어두운 화면을 바꿉니다. 처음에는 밝은 화면입니다.      |
| 아이콘 버튼                     | 마우스를 올리면 이름이 나옵니다.                                   |

## 스크롤 방식

열마다 스크롤 위치를 따로 저장하지 않고 두 값으로 나눠 저장합니다.

```
열의 위치 = 공통 위치 + 그 열의 어긋남
```

- 휠을 굴리면 **공통 위치**가 바뀌어 모든 열이 같은 거리만큼 움직입니다.
- Shift + 휠이나 스크롤바로 한 열을 움직이면 그 열의 **어긋남**만 바뀝니다.
- 한 열이 끝에 닿아 멈춰도 어긋남은 그대로라서, 돌아올 때 맞춰 둔 정렬이 되살아납니다.

원본과 수정본은 컷 사이 간격이 달라서 자동으로 맞출 수 없으므로, 같이 움직이다가 어긋나면 Shift + 휠로 맞추는 방식입니다.
계산은 `js/scroll.js` 위쪽에 있습니다.

## 폴더 구조

```
index.html
style.css
js/
  main.js     시작 지점
  state.js    열과 확대 비율의 상태, 열 추가·닫기·이동 규칙
  scroll.js   스크롤과 확대·축소 (계산 + 휠 입력 + 화면 반영)
  ui.js       화면 부품 (열, 도구 띠, 알림, 열 끌기, 파일명 표시)
test/         상태 규칙과 스크롤 계산 테스트
```

## 실행

ES 모듈을 쓰기 때문에 파일을 더블클릭해서 열면 동작하지 않고, 서버로 열어야 합니다.

```
python -m http.server
```

실행한 뒤 `http://localhost:8000`으로 접속합니다. VS Code의 Live Server 확장도 쓸 수 있습니다.
GitHub Pages에 올리면 별도 설정 없이 동작합니다.

## 개발

Node.js가 필요합니다.

```
npm install
npm test            # 상태 규칙과 스크롤 계산 테스트
npm run lint        # 코드 검사
npm run format      # 코드 모양 자동 정리
```
